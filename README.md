# ПАИНЦЫ 3D · Молочные войны

Браузерная криминальная комедия от первого лица. В вымышленной версии Паинцев Лысьвенского городского округа Пермского края фермер выходит на смену. Молоко приносит деньги, а местные забияки мешают добраться до приёмного пункта.

## Запуск

Нужны Node.js 22.12+ и настольный браузер с WebGL 2, клавиатурой и мышью.

```sh
npm install
npm run dev
```

Откройте адрес из вывода Vite (обычно http://127.0.0.1:5173). Нажмите «Начать игру» и разрешите браузеру захватить мышь. Все модели создаются локально, звук синтезируется через Web Audio.

## Первая смена

У остановки нажмите Q и выберите ответ цифрой. Можно также уйти от сборщика пешком. Стрелка показывает место текущей цели. Журнал (J) хранит задания смены, поручения и отношения с жителями.

Пройдите через проём в ограде перед молочной фермой. Посмотрите на ближайшую корову и нажмите E. Одно доение даёт 2 литра. Корова снова готова через 24 игровых секунды. Корм за 20 ₽ (F возле коровы) увеличивает следующий удой этой коровы до 4 литров.

Перейдите через дорогу к прилавку «Приём молока». Нажмите E, чтобы продать весь запас по базовой цене 35 ₽ за литр молока с поправкой на доверие жителей и 190 ₽ за банку сливок. Чтобы сделать сливки, нажмите F у прилавка с 4 литрами молока. Через 6 игровых секунд заберите банку той же клавишей. Сепаратор обрабатывает одну партию за раз.

В журнале есть четыре оплачиваемых поручения первой смены. Подоите корову, сдайте молоко, выдайте корм и продайте сливки по очереди. Награда за каждый этап поступает автоматически. После последнего задания можно продолжать смену.

Три забияки патрулируют улицы. Они видят игрока перед собой, замечают его вблизи и проверяют место, где потеряли его из виду. Во время замаха можно отступить или уйти в сторону. Цельтесь в корпус к моменту попадания. Кулаки бьют быстрее всего, скалка и лопата наносят больше урона, а вилы достают дальше всего. При нулевом здоровье игра загружает последнюю контрольную точку. Дома можно восстановить здоровье. Пауза останавливает бой и производство. Новая смена сбрасывает прогресс.

| Управление | Действие |
|---|---|
| WASD и мышь | Ходьба и обзор |
| Shift | Бег |
| Пробел | Прыжок |
| 1 / 2 / 3 / 4 | Кулаки / лопата / скалка / вилы |
| Левая кнопка мыши | Удар |
| E | Доение или продажа всей продукции |
| F | Кормление, запуск сепаратора или получение сливок |
| Q и цифры 1–7 | Взаимодействие с персонажами и предметами, выбор ответа |
| J | Журнал и доска поручений |
| W/S, A/D в тракторе | Газ и задний ход, поворот |
| Esc | Пауза и освобождение мыши |

Сценарий восьми глав, условия побочных поручений и финалы описаны в [сюжетном документе](docs/STORY.md). Контрольные точки хранятся в этом браузере.

## Проверки

```sh
npm run typecheck
npm run build
npm run preview
```

Production-сборка находится в dist. Её можно разместить на статическом хостинге. Для физики используется локально упакованный WebAssembly Rapier.
